Coding & Web Dev Notes 🍓

🌐 HTML5 (STRUCTURE)
1. HTML Introduction & Tags

HTML ka matlab HyperText Markup Language hai. Yeh kisi bhi website ka basic structure (dhancha) banati hai.

<!DOCTYPE html> <html> <head> <title>My Page</title> </head> <body> <h1>Hello World</h1> </body> </html>
2. Common HTML Elements

Important tags jo website mein content daalne ke kaam aate hain:

  • <h1> to <h6> - Headings ke liye.
  • <p> - Paragraph text likhne ke liye.
  • <a href="url"> - Links jodne ke liye.
  • <img src="image.jpg"> - Images dikhane ke liye.
🎨 CSS3 (DESIGN & STYLE)
1. CSS Basics & Selectors

CSS (Cascading Style Sheets) se HTML blocks ko sundar banaya jata hai (colors, fonts, layout).

/* Element Selector */ h1 { color: #db2777; text-align: center; } /* Class Selector */ .strawberry-box { background-color: pink; border-radius: 10px; }
2. Box Model & Padding-Margin

Har HTML element ek box hota hai jisme ye cheezein hoti hain:

  • Content: Asli text ya image.
  • Padding: Content aur Border ke beech ki andaruni jagah.
  • Border: Box ke charo taraf ki line.
  • Margin: Border ke bahar ki khali jagah.
